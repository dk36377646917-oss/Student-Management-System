# Student Management System

## About the Project
This is a simple Student Management System developed using Python and Object-Oriented Programming (OOP) concepts.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Features
- Add Student Details
- View Student Details
- Manage Student Records

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file.

## Project Type
Beginner Python Project
